# Kitty Config

My [Kitty](https://sw.kovidgoyal.net/kitty/) terminal configuration with a custom Carbonfox-inspired theme.

## Installation

```sh
git clone git@github.com:0XAiI/Kitty_Config.git ~/.config/kitty
```

## Layout

- `kitty.conf` - main configuration (FiraCode Nerd Font, 11pt)
- `current-theme.conf` - colorscheme (Carbonfox-inspired, blue-grey palette)

## Reload

Changes apply on save. To reload manually: `Ctrl+Shift+F5` or `kill -SIGUSR1 $(pidof kitty)`.
